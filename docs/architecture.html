Data Flow

1
Filter Selection
User selects filters via FilterBar (period, warehouse, category, status)
2
Reactive Watch
useFilters.js singleton refs trigger view watchers
3
API Request
api.js builds query params and sends GET via Axios
4
Server Filter
FastAPI applies apply_filters() and filter_by_month() on in-memory data
5
Pydantic validates response models
Validation
6
Render
Vue computed properties derive display data, templates re-render
